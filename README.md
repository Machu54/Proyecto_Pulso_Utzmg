# Pulso - Sistema de Monitoreo de Salud para Adultos Mayores

# Objetivo
Crear un sistema digital e integral para monitorear en tiempo real la salud y seguridad de los adultos mayores en el hogar, proporcionando asistencia inmediata durante emergencias, facilitando el seguimiento médico y brindando tranquilidad a sus familias y doctores

# Descripción General
Pulso es un ecosistema tecnológico diseñado para el cuidado de los adultos mayores. Utiliza un smartwatch con Wear OS (Kotlin) para monitorear constantes vitales y detectar caídas, una aplicación móvil en React Native que envía alertas en tiempo real a familiares y cuidadores, un portal web en Vue.js y Laravel para que los médicos consulten historiales, y recordatorios de medicamentos por voz mediante Alexa. Todo el sistema opera con base de datos MongoDB e implementación de cifrado de seguridad de extremo a extremo.
